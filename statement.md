# CampusConnect - Project Statement

## 1. Project Title

CampusConnect - Smart College Student Management System

---

## 2. Problem Statement

Managing student records, attendance, marks, and academic performance manually can be time-consuming and difficult to maintain.

CampusConnect is designed to provide a simple centralized system for managing these academic records through a graphical user interface.

The system allows users to manage student information, record attendance, manage marks and grades, and generate student performance reports.

---

## 3. Project Scope

The scope of CampusConnect includes:

- Student record management
- Student attendance management
- Marks and grade management
- Student performance reports
- Dashboard-based navigation
- File-based data storage using CSV files

The project is designed as a desktop Java application and focuses on basic academic record management.

---

## 4. Target Users

The intended users of CampusConnect are:

- College administrators
- Faculty members
- Teachers
- Academic staff

The system can be used to manage basic student academic information in a college environment.

---

## 5. High-Level Features

### Student Management

- Add students
- Search students
- Update student information
- Delete students
- View all students

### Attendance Management

- Record attendance
- View attendance records
- Calculate attendance percentage

### Marks & Grades

- Add student marks
- View marks
- Calculate average marks
- Calculate grades

### Student Reports

- Generate student performance reports
- Display student information
- Display attendance percentage
- Display marks, average, and grade

### Dashboard

- Display student statistics
- Provide quick access to major modules
- Provide centralized navigation

---

## 6. Project Technology

- Java
- Java Swing
- CSV File Storage
- IntelliJ IDEA
- Git
- GitHub

---

## 7. Project Objective

The main objective of CampusConnect is to create a simple, modular, and user-friendly college student management system that demonstrates Java programming, object-oriented programming, file handling, GUI development, modular architecture, and basic software engineering practices.
